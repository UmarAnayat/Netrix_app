### The Idea

> Lobby screens and living rooms need presence.  
> Netrix was drawn for distance viewing.

**Netrix** turns a shared file library into a TV-style media board.  
It brings browsing and previewing into one calm experience — designed for rooms where clarity from a distance matters more than phone-first density.
